## Les projets à évaluer

### 1. ProjetPOO
Simulation console d'un distributeur automatique mettant en pratique les concepts avancés de la POO (abstraction, héritage, polymorphisme, interfaces, composition, pattern Factory).

📄 README dédié et projet se trouvant ici : `ProjetPOO/README.md`

---

### 2. LinqEvaluation
Logiciel de conversion qui permet de rechercher, trier et exporter une liste de films au format XML, en mettant en pratique LINQ.

📄 README dédié et projet se trouvant ici : `LinqEvaluation/README.md`

---

### 3. OptimisationImagesMVP
Script C# qui parcourt un dossier d'images locales et génère pour chaque image plusieurs résolutions (1080p, 720p, 480p) au format WebP.
Deux versions : séquentielle et parallèle (Parallel.ForEach).

📄 README dédié et projet se trouvant ici : `OptimisationImagesMVP/README.md`

---

### 4. OptimisationImagesV1 _(bonus)_
Version avancée du MVP : lit un fichier JSON contenant des URLs Unsplash, télécharge les images via HttpClient, puis les convertit en WebP aux 3 résolutions. Deux versions : séquentielle et parallèle.
Reprend la logique de l'optimisation d'images du MVP, mais avec des images téléchargées depuis Internet.

📄 README dédié et projet se trouvant ici : `OptimisationImagesV1/README.md`
